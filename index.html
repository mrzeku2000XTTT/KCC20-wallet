How launch works
  • Ticker — 2–8 letters/numbers. The symbol on the book. Example: TEST, KAHA.
  • Name — Display name. Example: Test Coin. 2–24 characters.
  • Max supply — Total tokens that can ever exist. Typical 1,000,000–1,000,000,000. Cook uses 8 decimals internally.
  • Premint — Tokens you receive at deploy. Use 1000+ so KasWare can see a holder UTXO. 0 = fair launch (you hold none until you mint).
  • Mint price — KAS someone pays per token after launch. 0 = free mint. Typical 0.01–1 KAS. Need ~1.2 TKAS on this address to deploy.

    4. 
              
  4. Then wait your interval — budget ÷ each buy = number of slices. Timer × remaining slices = how long the plan runs.
