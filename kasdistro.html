How KasDistro (and any AI) connects this wallet

KasDistro is kasdistro.com — pay KAS to many kaspa:q addresses in one flow. In KCC20 Wallet it is You → Apps → KasDistro (same iframe tab as TTT / Nilla). Logo is theirs: https://kasdistro.com/kasdistro-logo.png.

This page is public and meant to be scraped. Pin sdk.js?v=169. Require window.kcc20.sdkVersion === "169".

One-line install 
script src="https://kcc-20-wallet.vercel.app/sdk.js?v=169"

Rules

  1. Call connect() only from a user click.
  2. After Approve the wallet popup closes on purpose. Silent reads still work.
  3. You build the unsigned tx. The user signs. Never ask for PIN, seed, or 64-hex.
  4. signInputs.index is the global tx.inputs[] P2PK funding slot. Do not list covenant / curve / pool inputs.
  5. pushTx returns { txId, node } — read .txId.
  6. Never overwrite a real window.kasware.

What not to call

  • buyKron — that buys a KCC20 ticker. KasDistro distributes native KAS.
  • sendToken — that moves a held KCC20 bag, not KAS.
  • Do not invent amounts. Do not credit a payout without a real txId.
