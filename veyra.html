The Sovereign Thread

DApps request. Wallets authorize. Users decide. Kaspa settles.

VEYRA is TTT Phase 6: a signing protocol for the Kaspa application layer. It is not a wallet and not a dApp. Scorpion (this PWA) is the open wallet that holds the boundary so TTT, KasDistro, Nilla, and your app can ask without owning the key.

Read the working spec: VEYRA.md. Clone the wallet instead of starting from scratch: FORK.md.
